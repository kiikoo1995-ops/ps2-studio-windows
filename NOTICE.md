# Avisos y licencias — rama experimental Play!

La versión **experimental** de PS2 Studio utiliza el motor de terceros
[Play!](https://github.com/jpd002/Play-), fijado al commit indicado en
`tools/play-engine.lock.json`. El motor no es un desarrollo original de PS2
Studio. La licencia del motor, incluida literalmente en el paquete bajo el
nombre `Play-LICENSE.txt`, permite redistribución con condiciones de
atribución, conservación del texto y descargo de responsabilidad.

El frontal PS2 Studio tiene licencia MIT. Sus términos no sustituyen los
términos del motor ni de sus dependencias. La compilación Windows incluye
componentes externos tales como **Qt** (pueden aplicar obligaciones LGPL y
oferta de código fuente) y **Mesa** (pueden aplicar avisos permisivos de autor).
**Antes de publicar a usuarios finales** se debe identificar cada archivo
realmente empaquetado y adjuntar sus licencias y avisos; un único aviso Play!
no garantiza cumplimiento de todo el paquete.

El código experimental no importa ni ejecuta PCSX2. La versión estable de
`main` sigue siendo, por separado, el lanzador PCSX2 0.3. El proyecto no
descarga ni distribuye juegos, firmware BIOS de Sony, claves, carátulas de
terceros ni archivos comerciales. Solo se deben utilizar homebrew libre o
imágenes obtenidas legalmente.

Las marcas PlayStation y PS2 pertenecen a sus titulares. Este proyecto no
está avalado por Sony, Play!, Qt, Mesa ni PCSX2. La versión independiente
**aún no está validada para publicación comercial, gráfica ni de rendimiento**.
