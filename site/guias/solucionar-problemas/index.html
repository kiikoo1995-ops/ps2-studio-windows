Guía práctica · Errores habituales

¿Un juego no aparece o no arranca?

Identifica si el problema está en la biblioteca, en la ruta de PCSX2 o en la configuración del propio emulador antes de modificar archivos.

1. PS2 Studio no encuentra el juego

  1. Comprueba que la carpeta que contiene el archivo está añadida en el lanzador.
  2. Verifica la extensión real del archivo y que no sea un ZIP o RAR que debas gestionar por separado.
  3. Si usas una pareja CUE/BIN, conserva ambos archivos juntos; es normal que la biblioteca evite duplicados de una pareja con el mismo nombre base.
  4. Actualiza la biblioteca tras mover o añadir archivos.

Consulta la guía de formatos para distinguir una imagen de disco de otros archivos.

2. El botón de iniciar no abre PCSX2

  1. Abre PCSX2 por separado desde Windows para comprobar que el programa está instalado y puede ejecutarse.
  2. En PS2 Studio, selecciona el archivo pcsx2-qt.exe correspondiente a tu instalación, no un acceso directo roto ni una carpeta.
  3. Confirma que el juego no fue movido o eliminado desde que añadiste la carpeta.
  4. Prueba primero la imagen legítima directamente en PCSX2; así podrás separar errores del lanzador y del emulador.

3. PCSX2 se abre, pero el juego no funciona

Revisa la configuración inicial de PCSX2, incluida la BIOS obtenida de tu propia consola, y consulta las advertencias del propio emulador. Que PS2 Studio enumere un archivo solo confirma que reconoce su extensión; no demuestra que sea una imagen válida ni compatible.

4. El juego funciona, pero va lento

Comprueba primero el rendimiento en PCSX2 sin pasar por el lanzador. Prueba la resolución interna predeterminada y actualiza controladores desde el fabricante. Evita ajustes agresivos que puedan causar fallos gráficos. Más consejos en la guía de rendimiento.

5. Windows muestra un aviso de aplicación desconocida

PS2 Studio todavía no está firmado digitalmente. Comprueba que el archivo procede de las publicaciones del repositorio oficial; no aconsejamos desactivar las protecciones del sistema ni ejecutar software cuya procedencia no puedas verificar.

6. Sigue fallando: informa del problema

Abre una incidencia en GitHub Issues indicando la versión del programa, la versión de Windows, la versión de PCSX2, la extensión del archivo y qué esperabas que ocurriera. No compartas archivos de juegos, BIOS, claves ni datos personales.
