PS2 Studio para Windows

Tu biblioteca local en una aplicación gratuita. Necesita PCSX2 instalado por separado.

VERSIÓN 0.3 · PRELIMINAR · WINDOWS

PS2 Studio

Aplicación portátil, sin registro ni suscripciones. El ZIP se aloja en GitHub Releases y contiene solo el lanzador, no PCSX2.

Descargar ZIP gratuito ↓

Verifica tu descarga con la suma SHA-256 oficial. En PowerShell ejecuta Get-FileHash .\PS2Studio-Windows.zip -Algorithm SHA256 y compárala con el archivo de suma de la misma publicación.

Si la actualización se está compilando o el enlace aún no está disponible, consulta las versiones publicadas. Ningún anuncio se presenta como enlace de descarga.

Requisitos

  • Un PC con Windows de 64 bits.
  • PCSX2 instalado desde su sitio oficial.
  • Una BIOS extraída de una consola PS2 propia, conforme a la legislación aplicable.
  • Copias de juegos obtenidas legítimamente.

Qué incluye la descarga

El ZIP contiene PS2Studio.exe, un lanzador independiente que no incluye PCSX2, juegos ni BIOS. Consulta el manual de uso para conocer los botones de la aplicación.

Novedades de la versión 0.3

  • Marca juegos con ★ Favorito y usa el filtro «Solo favoritos». Los favoritos se conservan localmente.
  • Detección de PCSX2 en ubicaciones habituales de Windows (si no se detecta, selecciónalo manualmente).
  • Archivo SHA-256 para comprobar la integridad del ZIP descargado.
  • Panel lateral con detalles y carátulas locales PNG/GIF. No descarga imágenes de Internet.

Instalación rápida

  1. Descomprime el ZIP en una carpeta de Windows.
  2. Abre PS2Studio.exe.
  3. Si no se detecta automáticamente, selecciona el ejecutable pcsx2-qt.exe de PCSX2.
  4. Añade las carpetas con tus imágenes de juegos y actualiza la biblioteca.

Es una versión inicial, sin firma de código y sin garantías de compatibilidad universal. Consulta la guía completa.
