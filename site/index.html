Una diferencia importante

No es un nuevo emulador.

PS2 Studio es una interfaz independiente para el emulador PCSX2, que se instala aparte. No contiene juegos, BIOS ni contenido de Sony. La versión actual es preliminar y todavía necesita pruebas completas de compatibilidad.
